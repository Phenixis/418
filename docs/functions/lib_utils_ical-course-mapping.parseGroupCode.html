    Function parseGroupCode

    • parseGroupCode(code: string): ParsedGroup[]

      Parses an ADE group code into one or two ParsedGroup records.

      A code like "2D2" maps to a single TP group { promo: "2", td: "D", tp: "2" }. A code like "2A" (no TP digit) expands to both tp: "1" and tp: "2", representing a full TD session that covers both subgroups.

      Parameters

      • code: string

        ADE group code to parse (e.g. "2D2", "2A").

      Returns ParsedGroup[]

      An array of parsed group coordinates, or an empty array if the code does not match the expected pattern.
