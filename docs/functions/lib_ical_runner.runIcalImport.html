    • runIcalImport(
          icalUrl: string,
          teacherMail: string,
          onProgress?: ProgressCallback,
      ): Promise<IcalImportResult>

      Fetches an iCal feed and upserts the corresponding resources and sessions.

      Events that do not match a known course (via mapSummaryToCourse) are silently skipped. Resources are keyed by course name and reused across events within the same import run to avoid duplicates. Sessions are upserted by their ADE UID so re-running the import is idempotent.

      Parameters

      • icalUrl: string

        URL of the iCal feed to import.

      • teacherMail: string

        Email of the teacher who owns the imported resources.

      • OptionalonProgress: ProgressCallback

        Optional callback called after each event is processed. Receives the current count and total event count.

      Returns Promise<IcalImportResult>

      An IcalImportResult with counts of created resources and sessions.

      Throws

      If the feed is unreachable or a database write fails.
