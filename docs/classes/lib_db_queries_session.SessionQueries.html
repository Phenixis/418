    Class SessionQueries

    Generic base class providing common CRUD operations backed by Drizzle ORM.

    Concrete query modules extend this class with table-specific methods while inheriting generic create/read/delete helpers. All mutations use soft deletes (setting deletedAt) unless explicitly calling hardDelete.
